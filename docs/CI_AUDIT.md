# CI·테스트 비용 점검 — 2026-11-16 (한국 시간)

## 완료 내용

Actions 및 자동 테스트 실행 설정 없음. 새 CI를 추가하지 않고 비용 원칙만 저장.

전체 연결 저장소 11개의 main 기준 워크플로·패키지 검사 명령·테스트 파일을 점검했다. 기본 예제 3개 외의 기능 회귀 테스트는 삭제하지 않았다. 자동 실행 빈도와 범위를 줄이고 필요한 전체 검증 경로는 유지한다. AGENTS.md에 이후 작업의 최소 관련 검사·중복 실행 방지·네이티브 빌드 범위·수동 출시 전 검증 원칙을 기록했다. Markdown은 소스 디렉터리 안에 있더라도 PR 자동 실행의 양수 경로에서 제외한다.

## 검증 결과

- main 트리에서 워크플로 없음 확인. YAML 실행 대상 없음.
- 변경 차이 공백 검사 및 PR/문서/게임/네이티브/수동 이벤트 조건 점검. 앱 동작 변경 없음. 전체 게임·브라우저·Android/AIT 빌드는 실행하지 않았다.
- 원격 Actions·스토어 업로드·운영 배포를 직접 실행하지 않았다. PR 생성은 main 반영 완료와 다르다.

## 남은 일

- PR 검토·머지와 원격 검사 결과 확인. 예산/사용 시간 초기화 여부는 이번 작업에서 확인하지 않았다.
- 게임 코드 변경만으로 네이티브 패키징이 생략될 수 있으므로 스토어 제출 전 최신 커밋의 수동 빌드·실기기 확인이 필요하다.
- 오래된 작업 브랜치는 최신 main을 반영한 뒤 재사용한다. 기존 브랜치는 수정·삭제하지 않았다.
